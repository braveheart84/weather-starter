# Weather Starter Themes

The theme selector includes the original visual design, saved as **Apple**, plus the 15 proposed theme directions below. The notes capture each direction's description and its main color, typography, card, and layout-density considerations.

## Apple

The existing Weather Starter design, preserved under the name Apple: a cool slate-blue gradient backdrop, white text, and translucent glass surfaces. Use light sans-serif typography with an oversized temperature reading, softly rounded frosted cards, and a spacious dashboard layout.
